# Cinematography and character motion

| Choice | Narrative use |
| --- | --- |
| Wide shot | Establish geography, scale, isolation |
| Medium shot | Gesture, interaction, readable action |
| Close-up | Reaction, emotional turning point |
| Extreme close-up | One significant detail; avoid unnecessary facial distortion |
| POV | Character perception; establish whose viewpoint |
| Over-the-shoulder | Relationship and eye line; maintain axis |
| Tracking | Follow purposeful movement with stable screen direction |
| Dolly in / out | Gradual intimacy or revealed isolation |
| Pan / tilt | Reveal or follow a subject along one axis |
| Orbit | Reveal spatial relationships; allow enough time and stable geometry |
| Low / high angle | Subjective power or vulnerability |
| Rack focus | Shift attention between two established depth planes |
| Depth of field | Separate subject without hiding required action |

Choose framing, angle, and one primary movement per shot; locked camera is valid. Avoid simultaneous pan/orbit/zoom/track requests. State start and end composition for movement, keep speed appropriate to shot length, and preserve action readability. Lens language is descriptive intent, not a guaranteed virtual camera setting.

Describe an action as preparation → movement → contact/result → reaction. Specify which hand moves, the target, and what happens to the object. Use one dominant action for short shots. Facial expression and gaze should follow motivation; avoid instantaneous emotional jumps. Hair, fabric, water, dust, and nearby objects react after the driving motion with restrained follow-through. Keep grounded foot contact and consistent momentum. Fast action benefits from wider framing and a held impact beat rather than constant camera shake.
