# Character identity and continuity

Inspect each available image using the available image-viewing tool. If no image inspection is available, state that limitation and obtain a user description; label its source accurately. For text-only characters, create one stable profile. Do not identify real people by name from images.

## Asset and identity records

Assign assets distinct roles: Character A identity/outfit, Character B identity/outfit, environment, style, opening composition, or prop. Multiple views of the same character share one character ID. Ask only when conflicting references or role ambiguity materially affect the result. Never average different characters into a blended face.

Profile fields: face shape and visible facial features; eye shape/color; hairstyle, length, volume and color; visible clothing, layers, colors and patterns; accessories; body proportions; art style. Mark occluded or unseen details as unknown. Choose framing that avoids inventing essential unseen details, or request a fuller image when exact preservation requires it.

Lock instruction: “Keep [character ID]'s observed face, eye shape, hair silhouette/color, outfit colors/layers/patterns, accessories, proportions, and rendering style consistent in every shot. Change only the requested pose, expression, camera, or environment. Do not swap attributes with other characters.” Include concrete observed traits, not only this generic sentence.

For image-to-video, preserve the supplied opening pose/composition when requested and introduce modest movement from that state. For reference-to-video, distinguish identity/style guidance from an exact first frame. Use human-readable asset labels unless the provider's actual tag syntax is verified.

## Continuity ledger

For every shot record entry → change → exit state:
- Character screen/world position, gaze, posture, emotion, motion direction.
- Left/right hand occupancy, prop ownership/orientation, grip, contact points.
- Outfit/accessories, hair silhouette, light direction, weather, setting.

Carry exit state into the next shot. An umbrella in the right hand stays there unless an on-screen transfer occurs. Preserve screen direction across cuts; motivate crossing the action axis with a neutral or visible repositioning shot. When generating separate clips, restate the necessary locks in each render brief and use supported endpoint references if available. Identity consistency remains a goal, not a guarantee.
