# Scene timing

Use editorial seconds, including decimals when helpful. With total T and N scenes, construct boundaries b0=0 < b1 < ... < bN=T. Scene i occupies [b(i-1), bi); its duration is bi-b(i-1). Adjacent boundaries must match exactly. The last endpoint is the final frame boundary, not an extra second.

Allocate based on narrative importance, natural speech plus pauses, action complexity, emotional reaction, camera travel, and transitions. Start from minimum feasible beat lengths, then give remaining time to the climax or emotional hold. Never divide evenly by habit. Example: 15 seconds across five scenes = 2 + 3 + 4 + 3 + 3.

Within each scene, budget establishing time, sequential action, dialogue, and reaction; overlapping sound/action is allowed only when physically coherent. Keep speech windows inside scene bounds. A one-second shot cannot contain a slow orbit, a long sentence, and three sequential gestures.

Hard cuts add no duration. A dissolve consumes time: either specify it within an existing timeline window or account for overlap as final length = sum of source clip lengths minus overlap. Do not double-count a transition or create unexplained gaps. Prefer hard cuts when fixed timing is tight.

When given too many mandatory beats for the duration, remove nonessential detail and shorten speech first. If mandatory content remains impossible, clearly identify the conflict and ask which constraint can change. Do not silently change an explicit total or scene count. For clip limits, distinguish editorial scenes from render segments; preserve the requested story timeline through editing.

Validation: sum durations, compare every adjacent end/start, verify zero start and exact total end, and check each dialogue/action window. Arithmetic validates the plan, not model compliance.
